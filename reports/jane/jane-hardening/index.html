What changed

Phase 1 — NATS removal

  • In-process events.ts EventEmitter replaced NATS JetStream (identical call surface).
  • Evidence: all producers + 4 consumers inside bridge/src, zero external consumers, orphaned streams.
  • NATS pods/svc removed from cluster (Flux v77 verified); NATS code path deleted, not dormant.

Phase 2 — k8s-only cutover

  • VM systemd deployment path deleted (services, Caddyfile, opencode sidecar). Chart is single source of truth.
  • Bridge: 1 replica, Recreate strategy, session PVC (jane-bridge-session, local-path 1Gi RWO), SESSION_STORE_PATH.
  • Hermes: restricted kubeconfig (jane-hermes-k8s SA, get pods=yes / delete nodes=no), 1y token Secret.
  • Bridge image 0.1.54 deployed; chart 0.1.63 → 0.1.66 staged (internal-api :3003 + /internal route + JANE_MCP_PERMISSION + backup + metrics).

Phase 3 — Seamless voice UX

  • STT model tiering: fast/full/auto (CPU cluster — no GPU; worker SchedulingDisabled).
  • TTS WAV streaming via WS binary frames + audio_start/audio_end framing (previously unwired — setSpeechService never called).
  • Barge-in: AnalyserNode RMS VAD, voice.interrupt, per-connection TtsState + epoch.
  • Wake-word: word-boundary prefix match, 30s backoff, pause during turns; PTT 120s cap; offline queue + message_ack; mic-permission banner.
  • Turn latency: turn.latency events → jane_turn_latency_ms histogram (Prometheus exporter :9464, no OTLP collector).

Phase 4 — Trustworthy execution + visible memory

  • Structured approvals: tool name+args passthrough, diff/dry-run preview captured from preceding tool.complete, two-tier confirm for destructive ops (3s arm, root exempt), TTS paused on checkpoint.
  • MCP tier fix: JANE_MCP_PERMISSION env (default devops) replaces hardcoded sandbox — tier bypass closed.
  • Visible memory: memory_list/search/delete MCP tools; internal-api :3003 (GET /internal/memories, PocketID JWT, CORS); deletes over WS gated devops+; PWA MemoryPanel with /memories nav.

Phase 5 — Ops hardening

  • LLM budget guard: MAX_LLM_CALLS_PER_HOUR (default 100) for autonomous runs; fixes pre-existing messages-vs-input body bug, dead trigger dedup (missing eventId), URL default drift (8645→8642).
  • Autonomous runs tagged X-Jane-Permission: root + X-Jane-Source: autonomous.
  • Backup CronJob: nightly hermes-home copy + mem0 GET /memories dump → local-path 5Gi PVC, 30d prune, podAffinity to hermes node.
  • Dashboard: ServiceMonitor for bridge :9464 + Grafana panels (turn latency p50/p95, tool failures, LLM calls/h) — gated on core.prometheus.enabled.
